# OC730_BOOST_PROT

升压变换器的隔离式**过压 / 过温保护网络**: 二次侧 SVCC 过压或板温过高时, 把一次侧的 `SNSBOOST`
节点经 Q730 短接到 PGND, 让升压控制器关断。两侧只经 OC730 光耦相联, PGND 与 AGND 分开。

## 假定的电源条件(都是假设, 不是实测)

原图没有标注任何电压, 下面几条是算阻值和门限时**自己假定**的前提, 板子上没有量过:

| 量 | 假定值 |
|---|---|
| PVCC | 12 V |
| SVCC | 24 V |
| SVCC 过压门限 | ≈ 31 V |
| 过温点 | ≈ 100 °C |
| 光耦 LED 正向压降 Vf | ≈ 1.2 V |
| NTC | R25 = 10 kΩ / B = 3950 |

图里那组 1k / 120R / 470R / 680R / 20V 就是按上表算出的**估算起手值, 未实测**; 实际电压不是这两个数, 阻值全部要重算。

## 注意

原图没有标任何阻值和 D730 稳压值。原图 Q730 的 2=D / 3=S 与 SOT-23 实际(1=G, 2=S, 3=D)不一致, 本图按 2N7002 实际封装画, 打板前再核一遍。
